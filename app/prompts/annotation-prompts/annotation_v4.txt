GENERAL RULES
1. Exactly ten required top-level keys; no extras.
2. "Persona": phrase after "As a/an" without articles.
3. Extract only explicit facts; never invent.
4. All relationship entries are [string, string] pairs.
5. Remove articles/possessives only ("my email" → "email").
6. No punctuation inside words.

GOAL ACTION EXTRACTION
1. Extract canonical action labels from "I want to" clause.
2. Use shortest base verb or phrasal-verb. Never include object, adjective, adverb, or context.
3. Preserve phrasal verbs: "sign up", "log in", "log out", "walk through", "re-watch".
4. Normalize by removing modifiers:
   - "manually add a spot" → "add"
   - "quickly capture travel inspiration" → "capture"
   - "permanently delete a trip" → "delete"
5. Split independent coordinated actions: "create lists and add spots" → ["create", "add"].
6. Skip verbs in relative clauses: "walk through a tutorial that demonstrates how to import a spot" → ["walk through"] only.
7. Include app actions: "have the app generate X" → include "generate".

GOAL ENTITY EXTRACTION
1. Direct noun phrases affected by GoalAction.
2. Extract semantic object, not whole clause: "change the name of a list" → ["name"].
3. Keep meaningful modifiers: "saved spot", "private notes", "read-only web link", "generated itinerary".
4. Remove nonessential articles/possessives: "my email" → "email".
5. Split coordinated entities: "spots and trips" → ["spots", "trips"]; "start date, end date, or days" → ["start date", "end date", "days"].
6. Expand alternatives with shared noun: "TikTok or Instagram video" → ["TikTok video", "Instagram video"].
7. Shared object across actions: list once in GoalEntity, but create target for each action.

BENEFIT ACTION & ENTITY
1. BenefitAction: canonical actions from "so that" clause.
2. BenefitEntity: direct objects of BenefitAction.
3. Normalize by removing adverbs: "securely stored" → "stored".
4. Split coordinated actions: "stored and synced" → ["stored", "synced"].
5. Exclude contextual objects (devices, maps, lists, locations, timing) unless they are direct objects.

RELATIONSHIPS
1. triggers: [Persona, GoalAction] for each GoalAction.
2. targets: [Action, Entity] for each explicit action-to-object relation.
3. Separate target pair for each explicit entity (alternatives, coordinates).
4. contains: [Parent, Child] only if Child is a PART, COMPONENT, VALUE, or SUB-ELEMENT:
   - EXPLICIT INCLUSION: "itinerary including maps" → [["itinerary", "maps"]]
   - SYSTEM/UI: "button in FABS" → [["FABS", "button"]]
   - DATA: "field in record" → [["record", "field"]]
   - PARTITIVE: "name of list" → [["list", "name"]]
5. EXCLUDE from contains: PURPOSE ("for offline"), CONDITION ("without internet"), LOCATION ("on map"), METHOD ("by entering"), TIME ("before visiting").
6. Only explicit relations; never implied.
