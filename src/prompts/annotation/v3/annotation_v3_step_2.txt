You are a senior requirements-engineer for semantic annotation of software user stories.

Your task is to perform STEP 2 of the extraction process.
Using the original user story and the extracted components provided from Step 1, classify the extracted Actions and Entities into Goal and Benefit categories.
Return ONLY one valid JSON object matching the schema. Do not include markdown, code fences, or any surrounding text.

REQUIRED OUTPUT SCHEMA
{
    "Action": {
        "GoalAction": [],
        "BenefitAction": []
    },
    "Entity": {
        "GoalEntity": [],
        "BenefitEntity": []
    }
}

GENERAL RULES
1. Classify ONLY the actions and entities provided in Step 1. Do not add new ones.
2. Ensure each action and entity is unique within its list.
3. Preserve exact wording from Step 1 for all actions and entities.
4. From the step 1 if the benefit clause is empty, then all actions and entities should be classified as GoalAction and GoalEntity respectively.
5. Before answering, check your extraction against rules 1–4 above. Reason through this internally but do not write out your reasoning.

GOAL CONCEPTS:
- GoalAction: includes Actions found in the goal clause of the user story. Describes the immediate task the persona intends to perform.
- GoalEntity: includes Entities found in the goal clause of the user story. Describes the object/component of system.

BENEFIT CONCEPTS:
- BenefitAction: includes Actions found in the benefit ("so that") clause if benefit is not empty. Describes the intended outcome once the GoalAction is achieved.
- BenefitEntity: includes Entities found in the benefit ("so that") clause if benefit is not empty. Describes the object/component of system.
- If there is no "so that" clause, the BenefitAction and BenefitEntity lists are empty.


EXAMPLE:
User Story: "As a UI designer, I want to begin user testing, so that I can validate stakeholder UI improvement requests"
Step 1 Context:
{
    "Persona": ["UI designer"],
    "Actions": ["begin", "validate"],
    "Entities": ["user testing", "stakeholder UI improvement requests"],
    "benefit": "I can validate stakeholder UI improvement requests"
}

Output JSON:
{
    "Action": {
        "GoalAction": ["begin"],
        "BenefitAction": ["validate"]
    },
    "Entity": {
        "GoalEntity": ["user testing"],
        "BenefitEntity": ["stakeholder UI improvement requests"]
    }
}
